# Project Information for AI/Portfolio Analysis

🔗 **Live URL**: https://glob-nfts.vercel.app

## Quick Summary

**GlobNFTs** is a gamified Web3 NFT platform with invite-only access, points-based leaderboard, and social task verification built on Ethereum.

## One-Line Description

Built a full-stack Web3 gamification platform with wallet authentication, invite codes, leaderboard ranking, and Discord integration using Next.js, MongoDB, and RainbowKit.

## CV-Ready Bullet Points

- **Engineered** a gamified NFT community platform with invite-only access, implementing SIWE authentication, rate-limited APIs, and real-time leaderboard with MongoDB
- **Integrated** RainbowKit and Wagmi for multi-wallet support, enabling secure Ethereum wallet connections across MetaMask, WalletConnect, and Coinbase Wallet
- **Developed** social task verification system with Discord OAuth, automating point rewards for server membership and engagement activities

## Key Technical Achievements

1. **Web3 Authentication**: Implemented Sign-In with Ethereum (SIWE) for secure, decentralized user authentication
2. **Gamification Engine**: Built points system with leaderboard rankings, whitelist tiers, and multiplier bonuses for NFT holders
3. **Invite System**: Created viral growth mechanism with invite codes, tracking, and automated weekly replenishment
4. **API Security**: Implemented rate limiting, input validation, and session management to prevent abuse
5. **Discord Integration**: OAuth flow with bot verification for server membership confirmation

## Technologies Used

Next.js 15, React 19, TypeScript, MongoDB, Mongoose, Tailwind CSS, Framer Motion, RainbowKit, Wagmi, Viem, SIWE, Discord OAuth, Vercel

## Project Category

Web3 / NFT / Full-Stack / Gamification / Community Platform

## Complexity Level

Advanced - Involves blockchain integration, OAuth, database design, and gamification logic
